## 3. Four-Gate Promotion Pipeline

```mermaid
flowchart LR
    A["Hermes Candidate"] --> B["Gate 1: Dev Partition (70%)"]
    B -->|Net Return > 0| C["Gate 2: Walk-Forward Validation (15%)"]
    B -->|Failed| X["Rejected"]
    C -->|WFE >= 0.6| D["Gate 3: Sealed Holdout (15%)"]
    C -->|Failed| X
    D -->|Net Return > 0 & DD <= 15%| E["Gate 4: Shadow Trading (50 Trades)"]
    D -->|Failed (Overfit)| Q["Permanent Quarantine"]
    E -->|Approved + No Churn| F["Active Production"]
```

1. **Development Gate (70% chronologically)**: Must achieve `net_return > 0`, `trade_count >= 10`, `fee_drag <= 0.35 * gross_pnl`.
2. **Validation Gate (15% chronologically)**: Walk-Forward Efficiency `WFE >= 0.60`, Deflated Sharpe Ratio `DSR >= 0.0`, Probability of Backtest Overfitting `PBO <= 0.40`.
3. **Holdout Gate (15% chronological sealed quarantine)**: Strict one-shot verification with `prom_gate_` cryptographic token. If failed, genome is permanently marked `quarantined`.
4. **Shadow Gate**: Must complete 50 paper trades with positive expectancy before live promotion.
5. **Promotion Churn Guard**: Maximum 1 promotion per 24 hours.

- **Primary Provider**: OpenCodex Gateway (`http://localhost:10100`) proxying `google-antigravity/gemini-3.7-flash` with `reasoning_effort='high'`.
